⚡ Pipeline Automatizado: Como Adicionar Novas Poses em Segundos

Fluxo automatizado para transformar conceitos raster (PNG/JPG) em SVGs prontos para a produção
1

Salve a Nova Imagem Conceito

Gere a ilustração (via Midjourney, DALL-E, Flux ou designer humano) e salve em:
public/mascot/concepts/[nome-da-pose].jpg
Exemplos: prisma-celebration.png, prisma-running.jpg.

2

Execute o Comando (Individual ou Seguro)

🎯 Modo Individual (Recomendado): Para vetorizar apenas a imagem nova sem tocar nas que já estão perfeitas:

$ npm run mascot:vectorize -- [nome-da-pose]

🛡️ Modo Incremental Seguro: Se rodar npm run mascot:vectorize sem argumentos, ele protege e pula automaticamente todos os SVGs que já existem, processando apenas os novos.

3

O SVG Está Pronto e Otimizado!

O motor VTracer gera automaticamente o arquivo em public/mascot/[nome-da-pose].svg, já sem fundo branco, com viewBox="0 0 1024 1024" responsivo e pronto para as micro-animações CSS.

4

Registrar no Componente (Opcional)

Adicione o novo estado em src/services/mascot/animationRegistry.ts para que o jogo saiba quando acionar a nova animação nas lições.

🧠 IA Gerando SVG vs Vetorização Automática (VTracer)

Por que você não deve pedir para uma IA gerar código SVG diretamente para ilustrações complexas:

Critério VTracer Automático IA Digitando SVG
Fidelidade Visual 100% Idêntica Deformada (Sem Olhos)
Tempo de Execução 0.4 segundos 30-60s (Streaming)
Custo de API $0.00 (Local Rust) Consome Tokens
Estilo e Cores Preservação Exata Inconsistente
💡 O Fluxo Ideal Recomendado:
1. Criação Artística: Use ferramentas de IA generativa (Midjourney, Flux, etc.) para criar o visual.
2. Vetorização: Use o comando automatizado npm run mascot:vectorize para traçar as curvas matemáticas perfeitas.
