1. Sumário Executivo & Mapeamento dos Arquivos

Este compêndio consolida a extração integral, exaustiva e sem omissões de todos os componentes de Design System, User Interface (UI), User Experience (UX) e Fluxos de Navegação (Flows) da plataforma Auramath. A base arquitetural segue rigorosamente a metodologia Spec-Anchored, na qual cada decisão de interface possui uma especificação normativa em OpenSpec e uma implementação em TypeScript/CSS estritamente sincronizada.

📌 Princípio Norteador da Plataforma
O Auramath rejeita a estética tradicional de aplicativos de matemática (fundos pretos opressivos, cores neon cansativas e gráficos punitivos de erro). A experiência é ancorada na metáfora do Caderno de Descoberta Matemática: papéis em tom Paper (#F7F4EA) e Cream (#FFFDF6), anotações em Nanquim Mineral Ink (#202522), acentos em Verdigris, Marigold, Coral e Iris, e física tátil 3D inspirada no padrão ergonômico consagrado pelo Duolingo com afundamento imediato a 0ms de latência.

2. Design System & Fundações Visuais

2.1 Metáfora do Caderno de Descoberta Matemática

O cálculo mental de alta velocidade exige foco cognitivo absoluto, clareza espacial e redução da ansiedade aritmética. O sistema visual foi concebido em torno do lema “Não calcule. Veja.”. O design elimina elementos distratores e fundamenta sua paleta em pigmentos clássicos de cadernos de anotações e laboratórios:

  • Papel Arqueológico & Prensado: O fundo nunca é um branco clínico puro (#FFFFFF) que ofusca os olhos, mas o tom Paper (#F7F4EA) e Cream (#FFFDF6).
  • Nanquim Mineral: Toda a escrita e contornos usam o pigmento Ink (#202522), transmitindo a solidez de tinta caligráfica nanquim sobre papel espesso.
  • Pátina Verdigris: A cor assinatura é o óxido de cobre Verdigris (#176B5B), evocando instrumentos de precisão antigos e compassos de latão oxidado.
  • Iluminação Marigold: O amarelo ouro Marigold (#F2B84B) marca os pontos de atenção ativa, as chamas da ofensiva diária e a antena de observação do mascote.

2.3 Theming Soberano & Contraste WCAG AAA

  • Modo Claro Imediato (Padrão no Cold Load): Ao carregar o aplicativo pela primeira vez, o tema é estritamente Light Paper (#F7F4EA) com superfícies em Cream (#FFFDF6). O contraste entre o texto em Nanquim Mineral (#202522) e o fundo Paper é superior a 11:1, superando com folga o padrão ouro WCAG AAA (mínimo de 7:1).
  • Modo Escuro Mineral: Quando ativado pelo usuário via ThemeToggle, a aplicação inverte para o fundo em Nanquim Mineral (#202522) com texto em Paper (#F7F4EA). Fica terminantemente proibido o uso de pretos OLED puros (#000000) ou pretos azulados cósmicos (#07090E).

2.4 Física Tátil 3D dos Botões (Duolingo-Inspired)

Inspirado na ergonomia tátil do Duolingo, cada botão interativo possui uma extrusão chanfrada inferior que simula um bloco físico prensado.

⚡ Regra de Zero Latência na Depressão Tátil
Ao tocar no botão (:active ou classe .is-active), a transição CSS é forçada para transition: none !important (0ms de latência). O elemento translada imediatamente 3px para baixo (translateY(3px)) e a sombra inferior reduz de 4px para 1px. Na liberação do toque, uma curva de mola suave de 80ms (cubic-bezier(0.16, 1, 0.3, 1)) restaura a posição original, acompanhada do clique procedural disparado via Web Audio.

2.5 Pilha Tipográfica Anti-Layout-Shift (CLS = 0)

Em sessões de cálculo contra o relógio, a mudança de um número com 1 dígito (ex: 7) para 4 dígitos (ex: 4896) ou a contagem decrescente de centésimos de segundo causa trepidação visual (layout shift) se as fontes tiverem larguras de caracteres variáveis.

  • Tipografia Numérica & Equações: Utiliza exclusivamente JetBrains Mono configurada com font-variant-numeric: tabular-nums. Cada glifo ocupa exatamente a mesma largura física na tela, blindando a interface contra qualquer oscilação de layout (Cumulative Layout Shift estritamente = 0).
  • Títulos e Display: Plus Jakarta Sans (Bold e ExtraBold) para hierarquia institucional, títulos de telas e banners de unidades.
  • Texto Geral e Dicas: Inter (Regular e Medium) para instruções didáticas e explicações teóricas.

4. Experiência do Usuário (UX) & Psicologia Sensorial

4.1 Filosofia da Descompressão Empática e Não-Punitiva

🛡️ Redução da Ansiedade Matemática
A literatura de psicologia cognitiva demonstra que sons estridentes de buzzer e telas piscando em vermelho produzem picos de cortisol e aversão ao cálculo mental. O Auramath adota ergonomia não-punitiva radical: erros são tratados como hipóteses naturais de ajuste estrutural.
  • Feedback Visual Acolhedor: Quando a resposta submetida é incorreta, nenhuma tela pisca em vermelho vivo. Em vez disso, a gaveta inferior FeedbackDrawer desliza suavemente em tom Coral Suave (#F8DED9), exibindo a mensagem reflexiva “Veja a estrutura oculta” acompanhada da decomposição passo a passo da operação.
  • Dissipação Serena de Energia: Se um combo longo for interrompido, as partículas e o multiplicador se desvanecem suavemente sem estalos ou ruídos punitivos. O mascote assume postura pensativa (thinking), apontando o esquadro para onde a simetria foi negligenciada.

4.2 Pedagogia Cinética de Decomposição Numérica

Ao contrário de interfaces tradicionais que exibem contas como fórmulas estáticas de livro, o Auramath transforma números em partículas cinéticas animadas da esquerda para a direita:

  • Animação de Fusão de Mercúrio (Adição Posicional Esquerda-Direita): Na soma $47 + 38$, o segundo operando se divide visualmente em $30$ e $8$. O bloco de $30$ desliza suavemente para se fundir com $47$, materializando o $77$ antes da incorporação do $8$ final, resultando em $85$.
  • Animação do Acordeão Elástico (Multiplicação por 11): Em $35 \times 11$, os dígitos $3$ e $5$ se afastam lateralmente com amortecimento elástico de mola. A soma central $(3 + 5 = 8)$ emerge no espaço intermediário e o número se fecha com travamento tátil em $385$.
  • Animação do Espelho Simétrico (Diferença de Quadrados): Em $48 \times 52$, um eixo de simetria vertical dourado surge no valor médio $50$. Duas asas simétricas indicam o desvio $d = 2$, animando a transformação imediata em $50^2 - 2^2 = 2500 - 4 = 2496$.

4.3 Sonoplastia Harmônica em Escala Pentatônica (Web Audio API)

O motor de áudio procedural (src/services/audioSynth.ts) sintetiza ondas sonoras em tempo real através da Web Audio API do navegador, sem downloads de arquivos de áudio externos:

  • Escala Pentatônica Ascendente: Cada acerto sequencial em um combo dispara a nota seguinte de uma escala pentatônica maior ascendente (Dó4, Ré4, Mi4, Sol4, Lá4, Dó5, Ré5...). Como escalas pentatônicas não contêm semitons de trítono dissonantes, o jogador nunca experimenta choques sonoros desagradáveis, gerando liberação contínua e prazerosa de dopamina.
  • Tick Tátil Mecânico: Cada toque em botão emite uma oscilação ultracurta de ruído senoidal amortecido de 12ms a 800Hz, reproduzindo a sensação física de uma tecla de alta precisão.

4.4 DNA Matemático & Radar Cognitivo de 5 Eixos

A performance do usuário é mapeada continuamente em 5 dimensões ortogonais:

  1. Velocidade: Tempo mediano de resposta em operações procedurais puras.
  2. Estimativa: Acurácia na ancoragem rápida de ordens de magnitude e limites de Fermi.
  3. Flexibilidade: Capacidade de alternar dinamicamente entre múltiplos métodos para o mesmo problema.
  4. Resistência: Manutenção de acurácia acima de 90% sob fadiga temporal em sessões prolongadas.
  5. Memória de Trabalho: Quantidade de variáveis intermediárias retidas mentalmente sem apoio visual.

5.3 Ciclo Pedagógico Tripartite por Nó

🔄 O Fluxo Obrigatório de Cada Lição da Trilha
Nenhum aluno é exposto a testes frios sem preparação conceitual. Cada nó da Trilha Curricular obedece a um ciclo em três fases:
  1. Fase 1: Descoberta Conceitual (Eureka): Demonstração interativa onde a propriedade matemática é revelada geometricamente antes de qualquer dígito ser digitado. O aluno manipula ou observa os números se agruparem.
  2. Fase 2: Andaimes Cognitivos Guiados (3 Tarefas): Três exercícios estruturados onde a decomposição intermediária é parcialmente preenchida (ex: preencher a dezena mais próxima ou a distância ao quadrado), guiando a linha de raciocínio.
  3. Fase 3: Bateria de Agilidade e Fixação (10 Questões): Dez cálculos procedurais diretos contra o relógio para converter a compreensão conceitual em memória muscular instantânea.
  4. Validação de Retenção (80% Mínimo): O nó só é conferido como concluído se a acurácia atingir no mínimo 80%. Resultados inferiores acionam uma sessão de reforço empático, preservando o aluno de frustrações em níveis subsequentes.

EXHIBIT 01: Especificação Normativa de UI & Design System openspec/specs/ui-design-system/spec.md 
## Purpose

Define a especificação normativa de design tokens, paleta cromática editorial "Caderno de Descoberta", tipografia tabular anti-layout shift, física tátil 3D e comportamentos visuais para todas as superfícies da plataforma Auramath.

## Requirements

### Requirement: Paleta Cromática Editorial e Theming Soberano
O sistema SHALL implementar um sistema de cores semânticas bidirecional baseado na metáfora do "Caderno Editorial de Descoberta Matemática" (*"Não calcule. Veja."*), eliminando fundos pretos cósmicos e neons elétricos.

#### Scenario: Aplicação dos tokens de cor de superfície e acento
- **WHEN** a interface renderiza no modo claro imediato (*cold load* padrão)
- **THEN** o sistema SHALL aplicar a cor de fundo Paper (`#F7F4EA`), superfícies elevadas em Cream (`#FFFDF6`), texto primário em Nanquim Mineral Ink (`#202522`), texto secundário em Lápis Grafite (`#5C645F`), acento de marca e nós concluídos em Verdigris (`#176B5B`), nós ativos e streak em Marigold (`#F2B84B`), acentos de relações algébricas em Iris (`#6E5AA6`) e correções pedagógicas não-punitivas em Coral (`#E76F61`).

#### Scenario: Suporte a Modo Escuro Mineral
- **WHEN** o usuário seleciona o tema escuro
- **THEN** o sistema SHALL inverter as superfícies ancorando o fundo em Ink Mineral (`#202522`) e o texto em Paper (`#F7F4EA`), mantendo o contraste de texto acima de 7:1 (WCAG AAA) e sem uso de `#000000` ou `#07090E`.

### Requirement: Botões Táteis 3D com Física de Depressão Imediata
Os botões primários e seletores SHALL implementar física tátil inspirada no Duolingo com chanfro chanfrado inferior e afundamento em tempo de resposta imperceptível.

#### Scenario: Compressão tátil 3D sem latência

# Technical Design: Auramath UI Design System & Visual Architecture

## Context

Para motivação e objetivos gerais desta mudança, consulte `proposal.md`. Para os requisitos normativos de comportamento da interface, consulte `specs/ui-design-system/spec.md`.

O Auramath é construído sobre **React Native com Expo** para suportar Web (PWA), iOS e Android a partir de uma única base de código. O cálculo mental de alta velocidade exige uma interface imersiva, com zero latência perceptiva, feedback tátil-visual imediato e foco cognitivo ininterrupto.

---

## Goals / Non-Goals

### Goals
- **Imersão & Ergonomia Visual**: Paleta Dark Glassmorphism que previne fadiga ocular durante sessões intensas de treino mental.
- **Zero Layout Shift (CLS = 0)**: Garantir que nenhum elemento da tela se mova quando os dígitos da conta mudarem de 1 para 4 caracteres ou durante a contagem de tempo.
- **Micro-interações de Toque a 120 FPS**: Componentes de digitação (`NumpadButton`) com resposta no evento `onTouchStart`, eliminando os 300ms de latência de cliques convencionais.
- **Acessibilidade de Alto Contraste**: Relação de contraste mínima de 4.5:1 (WCAG AA) e áreas mínimas de toque de 56x56dp para botões interativos.

### Non-Goals
- Não suportar tema claro (Light Mode) na tela de jogo principal; o universo sensorial do Auramath e os efeitos de plasma bioluminescente são projetados especificamente para contrastar sobre o fundo cósmico Midnight Obsidian.
- Não utilizar bibliotecas pesadas de UI de terceiros (como Material UI ou Paper); todos os componentes são estilizados através de design tokens puros e primitivos do React Native com Reanimated.

---

### 2. Pilha Tipográfica Híbrida & Glifos Tabulares

```
+-------------------------------------------------------------------------+
|                           PILHA TIPOGRÁFICA                             |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ DISPLAY / HEADINGS ]       Space Grotesk / Plus Jakarta Sans (Bold)  |
|  - Títulos de tela            "AURAMATH", "BLITZ 60s", "GRAU IV"        |
|                                                                         |
|  [ NÚMEROS / EQUAÇÕES ]       JetBrains Mono (tabular-nums / 700)       |
|  - Equação central            "4 8  x  5 2  =  [ 2496 ]"                |
|  - Cronômetros e placares     "00:42.85"                                |
|                                                                         |
|  [ UI / CORPO DE TEXTO ]      Inter (Regular / Medium)                  |
|  - Rótulos, teoria e dicas    "Divida por 4 e multiplique por 100"      |
|                                                                         |
+-------------------------------------------------------------------------+
```

* **Decisão:** Forçar `font-variant-numeric: tabular-nums` e largura monoespaçada estrita em todo o pipeline de números.
* **Racional:** Em fontes não-tabulares, o número `1` tem largura de 8px e o `8` tem largura de 14px. Quando o cronômetro ou a conta muda, o layout trepida em alta velocidade (layout shift), cansando o cérebro. Com `tabular-nums`, todos os números ocupam exatamente a mesma largura física na tela.
* **Alternativas consideradas:** Usar fonte comum do sistema (`Roboto` / `San Francisco`) sem configuração tabular (rejeitada por jitter visual severo).

### 4. Tratamento dos Componentes Táticos

#### A. `NumpadButton` (Tecla do Teclado In-App)
- Dimensão: Mínimo de 56x56dp (proporção áurea no grid 3x4).
- Superfície: Fundo `rgba(255, 255, 255, 0.04)` com borda fina de 1px `rgba(255, 255, 255, 0.08)`.
- Reação ao Toque: Disparada no evento `onTouchStart` (zero delay).
- Animação: `scale: 0.96` instantâneo com elevação de borda para `primary-cyan`.

#### B. `EquationDisplay` (Painel Central da Equação)
- Fundo: Dark Glass com gradiente sutil de 135° de `#0D111A` a `#131926`.
- Dimensão de glifos: Altura mínima de 64dp, permitindo que a quebra de números (pedagogia cinética) tenha espaço de respiro sem colidir com as bordas.
- Ancoragem do Mascote: O mascote Aura paira logo acima ou na lateral superior direita do painel.

#### C. `TrackNode` (Nó da Trilha de Aprendizado)
- Círculo de 72dp com anel de progresso em SVG circular.
- Estado Ativo: Halo de pulsação suave em ondas senoidais (`scale: [1, 1.06, 1]`).
- Estado Concluído: Preenchimento gradiente ciano com 1 a 3 coroas douradas em relevo.

### 5. Regras Visuais & Design Laws

1. **Lei do Foco 80/20:** 80% do peso visual da tela deve pertencer à equação e ao teclado numérico. Todos os elementos de cabeçalho (tempo, streak, botões de pausa) devem usar opacidade reduzida (`opacity: 0.65`) quando a rodada estiver em andamento.
2. **Lei do Toque Cego:** O teclado in-app não deve mudar de posição durante a partida. A geometria do teclado deve permanecer fixa para permitir que a memória muscular dos dedos atue sem necessidade de olhar para o teclado.
3. **Lei da Descompressão Empática:** Erros visuais devem transmitir acolhimento e clareza, nunca agressividade. Nenhuma tela deve piscar em vermelho total.

## Risks / Trade-offs

* **[Risk: Performance de Backdrop-Filter em Celulares Antigos]**

    case 'sm':

      return isDark ? '0 12px 24px rgba(0, 0, 0, 0.6)' : '0 12px 24px rgba(15, 23, 42, 0.12)';
    case 'md':
    default:
      return isDark ? '0 4px 12px rgba(0, 0, 0, 0.5)' : '0 4px 12px rgba(15, 23, 42, 0.08)';
  }
}

O sistema de gamificação sensorial orquestra o feedback audiovisual e tátil em tempo real para maximizar o engajamento cognitivo, dopamina e prazer no cálculo mental, combinando animações fluidas a 60/120 FPS, sonoplastia em escala pentatônica musical harmônica, vibração háptica escalar e o mascote reativo "Aura".

## Requirements

### Requirement: Mascote Reativo Interativo "Prisma"
O sistema SHALL exibir em destaque o mascote oficial "Prisma, o Camaleão Geômetra", construído em SVG vetorial de alta precisão com crista de transferidor graduada de 180°, esquadro triangular de acrílico 30°-60°-90° e cauda em espiral áurea de Fibonacci, cuja postura visual e micro-animações reagem dinamicamente aos eventos de cálculo, acerto, sequências de combo e reflexão através de 6 estados emocionais canônicos (`idle`, `thinking`, `hint`, `eureka`, `supernova`, `camouflaged`).

#### Scenario: Evolução do mascote durante sequência de combo (5 Níveis)
- **WHEN** o usuário atinge os patamares de combo de 1, 5, 10, 20 e 35 acertos consecutivos
- **THEN** o mascote "Prisma" SHALL transitar visualmente pelas reações progressivas correspondentes:
  1. *Nível 1 (Combo 1-4):* Postura `idle` com respiração peitoral suave (`scaleY`), piscar periódico (4s) e olhar atento aos ângulos da questão.
  2. *Nível 2 (Combo 5-9):* Sorriso confiante, leve inclinação com o esquadro em prontidão e início de brilho áureo sutil.
  3. *Nível 3 (Combo 10-19):* Olhar entusiasmado e aura luminescente dourada (`drop-shadow`) reforçada pelo filtro de combo.
  4. *Nível 4 (Combo 20-34):* Estado `eureka` vibrante com salto elástico com amortecimento (*squash & stretch*).
  5. *Nível 5 (Combo 35+):* Estado `supernova` pleno, com auréola solar geométrica de 360° em rotação contínua e confetes poligonais em órbita.

#### Scenario: Descompressão suave ao errar
- **WHEN** o usuário erra uma questão durante qualquer patamar de combo
- **THEN** o sistema SHALL dissipar a energia acumulada sem sons estridentes ou punições agressivas, e o mascote SHALL adotar postura empática `thinking` ou `hint`, apontando o esquadro e incentivando a visualização da simetria oculta através do balão editorial ("Não calcule. Veja!").

A interface visual SHALL renderizar as operações matemáticas não como texto estático, mas como partículas numéricas cinéticas animadas da esquerda para a direita, demonstrando visualmente os algoritmos cognitivos de decomposição.

#### Scenario: Animação de Fusão de Mercúrio (Adição Posicional)
- **WHEN** o usuário resolve ou visualiza o passo a passo de uma adição posicional da esquerda para a direita

#### Scenario: Animação do Acordeão Elástico (Multiplicação por 11)
- **WHEN** uma operação de multiplicação por 11 é demonstrada
- **THEN** os dígitos do multiplicando SHALL afastar-se lateralmente com efeito de mola elástica, abrindo espaço para a materialização da soma intermediária no centro e fechando-se com travamento tátil instantâneo.

#### Scenario: Animação do Espelho Simétrico (Diferença de Quadrados)

- **THEN** o sistema SHALL exibir de 3 a 5 exercícios guiados onde campos intermediários de decomposição devem ser preenchidos

#### Scenario: Execução da bateria de fixação
- **WHEN** o usuário conclui com sucesso a fase de andaime

function parseRoute(): AppRoute {
  if (typeof window === 'undefined') {
    return { type: 'track' };
  }
  const hash = (window.location?.hash || '').replace(/^#\/?/, '').trim();
  let pathname = (window.location?.pathname || '').replace(/^\//, '').trim();
  if (pathname.startsWith('auramath/')) {
    pathname = pathname.slice('auramath/'.length).trim();
  } else if (pathname === 'auramath') {
    pathname = '';
  }
  const segment = hash || pathname;

  if (segment === 'dev' || segment.startsWith('dev/')) {
    return { type: 'dev' };
  }
  if (segment.startsWith('lesson/')) {
    const nodeId = segment.slice('lesson/'.length).trim();
    if (nodeId) {
      return { type: 'lesson', nodeId };
    }
  }
  if (segment === 'train' || segment.startsWith('train/')) {
    return { type: 'train' };
  }
  if (segment === 'duels' || segment.startsWith('duels/')) {
    return { type: 'duels' };
  }
  if (segment === 'profile' || segment.startsWith('profile/')) {
    return { type: 'profile' };
  }
  return { type: 'track' };
}

/**
 * Normalizes stage prop into a strict 1..5 numeric tier.
 */
export function resolveStageNumber(stage?: AuraMascotStage, combo: number = 1): 1 | 2 | 3 | 4 | 5 {
  if (typeof stage === 'number' && !isNaN(stage)) {
    return Math.max(1, Math.min(5, Math.round(stage))) as 1 | 2 | 3 | 4 | 5;
  }
  if (typeof stage === 'string') {
    const map: Record<string, 1 | 2 | 3 | 4 | 5> = {
      dot: 1,
      line: 2,
      shape: 3,
      pattern: 4,
      insight: 5,
    };
    const mapped = map[stage.toLowerCase()];
    if (mapped) return mapped;
  }
  return combo >= 35 ? 5 : combo >= 20 ? 4 : combo >= 10 ? 3 : combo >= 5 ? 2 : 1;
}

/**

 */
export function mapToPrismaState(state?: AuraMascotState, stageNum: number = 1): PrismaMascotState {

  if (state === 'hit') return 'thinking';
  if (state === 'thinking') return 'thinking';
  if (state === 'supernova' || stageNum === 5) return 'supernova';

}
